## Recommended project setup

From the repository root, install Impeccable using the official installer appropriate to Codex. The current docs list:

```bash
npx impeccable install
```

The documentation says Codex uses `$impeccable`, and `PRODUCT.md` / `DESIGN.md` are the main shared context files.

## First design pass

After the skeleton exists:

```text
$impeccable design the application workbench for this project using PRODUCT.md and DESIGN.md. Keep the job ledger/workbench character, avoid generic AI dashboard patterns, and build directly in code.
```

Then:

```text
$impeccable critique the application workbench. Focus on hierarchy, density, clarity of the capture flow, mobile usability, and whether the interface feels like a real personal tool rather than an AI-generated dashboard.
```

Then:

```text
$impeccable audit the UI and fix relevant accessibility, layout, and consistency problems without adding decorative UI.
```

The official docs describe code-led design as a direct-to-code workflow and explain that design work should be judged by truth, purpose, consequence, feasibility, and fit.
