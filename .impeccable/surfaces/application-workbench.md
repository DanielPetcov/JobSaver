# Application Workbench

## Purpose
The home route is a private job-application ledger. Its one primary task is turning a pasted public job URL into a reviewed application, while making saved applications quick to scan and update.

## Hierarchy and layout
- Header: product name, quiet single-user context, no dashboard metrics.
- Capture strip: URL label, one wide URL field, Extract action, inline status/error.
- Review surface: appears after extraction; editable, structured fields with Save as application as the sole primary action.
- Ledger: a semantic table on wide screens and dense article rows on narrow screens; company/role lead, status/date/supporting skills follow.

## Interaction
Keyboard focus is always visible. Extraction and save states are announced. Status uses written labels alongside restrained visual treatment. On small screens, the capture flow stays above the ledger and fields stack without horizontal scrolling.
